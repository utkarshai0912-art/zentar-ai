==============================
FEATURE: USER SECRETS VAULT
==============================

Create a new page:

Settings → API Keys & Integrations

Users should be able to securely manage their own credentials without relying on platform-owned API keys.

The application owner should also have the option to provide platform API keys, but users can override them with their own.

AGENT INTEGRATION
=================================

Every AI Agent, Workflow, Browser Agent, MCP Tool, and Automation should automatically use the authenticated user's configured credentials.

The system should:

- Detect available providers
- Use the user's preferred provider
- Automatically fall back to another configured provider if one fails
- Never expose secrets to other users

=================================
SECURITY
=================================

- Encrypt all secrets before storing them.
- Never return secrets through APIs.
- Never expose secrets in logs.
- Mask values in the UI.
- Require re-authentication before revealing sensitive values.
- Every user can only access their own credentials.
- Record audit logs for all credential changes.
